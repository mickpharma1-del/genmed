# SuperGenKart – Production Launch Blueprint

This repository now contains the deploy-ready planning assets for building **SuperGenKart Pharmacy Ecommerce + Admin + AI** as a production Node.js stack.

## What is included

- A normalized **master build prompt** for AI coding tools.
- A concrete **next-step execution plan** to start with backend architecture first.
- A practical **Node.js backend folder structure** with route and module mapping.

## Recommended immediate sequence

1. Backend bootstrap (Express + Mongo + Firebase auth middleware).
2. Admin-auth and product APIs.
3. Cart/checkout/order lifecycle.
4. Admin dashboard and operational modules.
5. AI assistant and substitute engine.
6. Frontend (Next.js app router) integration.

See `docs/SUPERGENKART_MASTER_PROMPT.md` and `docs/NEXT_STEPS_BACKEND_FIRST.md`.
